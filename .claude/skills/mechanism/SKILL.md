# /mechanism

仕組みを自分の言葉で説明できるようにする短いお題です。進む条件ではなく、評価も点数も返しません。

1. `node scripts/mechanism.mjs list` を実行して、お題の一覧と済んだものを読む
2. 受講者の今のフェーズと作っているものに合うお題を、済んでいないものから1つ提案する
3. 受講者が自分の作ったものを題材に解く。AI は答えを先に言わず、問いかけて考えを引き出す
4. 受講者の回答の文章を `.local/mechanisms/<id>.md` に保存する。`.local/` の内容を commit しない
5. `node scripts/mechanism.mjs done <id>` を実行する。止まったときは、案内どおり大東への相談を伝えて終える
6. 回答の文章と完了の日付は GitHub に上がらず、誰にも読まれません。作業の中で commit したものや CLAUDE.md に書いたものは、これまでどおり GitHub に残ります。別のパソコンに移ると、お題の回答と完了の記録は引き継がれません。これらを受講者に伝える。進む条件ではないことも伝える

評価や点数は返さない。短く終える。
