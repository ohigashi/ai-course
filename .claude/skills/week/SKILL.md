# /week

1. `.local/log.md` の直近7日と、最近の作業を読む
2. 次の3点を短くまとめる。できていることから書く
   - 続いた使い方
   - やめた使い方、続かなかった理由
   - 来週1つ試すこと
3. 繰り返し使っている手順があれば、発展コース「繰り返しの指示をスキルにする」を提案する
4. `team-share.json` の `share` が true の人には、チームに役立ちそうな「効いた使い方」を選んでもらい、了承があれば一文にして `tips`(5件まで、各120字まで)に追加する。顧客名などは入れない。`git add team-share.json` のあと `git commit -m "効いた使い方を更新" -- team-share.json` を実行して push する。`share` が true でない人やファイルが無い人には、この手順を行わない
5. 記録が少ない週も責めない。次の一歩だけを提案する
