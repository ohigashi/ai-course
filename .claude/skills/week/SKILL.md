# /week

1. `.local/log.md` の直近7日と、最近の作業を読む
2. 次の3点を短くまとめる。できていることから書く
   - 続いた使い方
   - やめた使い方、続かなかった理由
   - 来週1つ試すこと
3. 繰り返し使っている手順があれば、発展コース「繰り返しの指示をスキルにする」を提案する
4. チームに役立ちそうな「効いた使い方」を受講者に選んでもらい、了承があれば、一文にして `team-share.json` の `tips`(5件まで、各120字まで)に追加する。顧客名などは入れない。commit と push をする
5. 記録が少ない週も責めない。次の一歩だけを提案する
