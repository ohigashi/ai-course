# /course-status

このスキルは大東の手元のコースのリポジトリで使います。

1. 手元の `members.local.json`(リポジトリの外に出ないファイル。形式は `[{ "github": "ユーザー名", "name": "名前" }]`)に、確認したいメンバーがいるかを確かめる。無ければ大東に聞いて追加する
2. `node scripts/status.mjs` を実行する
3. 生成された `out/team.html` を開く
4. 段階ごとの状況と、更新が止まっている人を短く大東に伝える。更新が止まっている人の話はページに載せない

`members.local.json` にない相手からの招待は承諾しない。受講者の内容を読むだけで、受講者のリポジトリを変更しない。
