# /log

1. 今日のやり取りから「どの仕事に AI をどう使ったか」の1行案を作り、受講者に見せて直してもらう。顧客名や数字の実データは書かない
2. 確定した1行を `.local/log.md` の末尾に `- YYYY-MM-DD 内容` の形で追加する
3. `node scripts/log.mjs` を実行する
4. `activity.json` だけを commit して push する。内容の `.local/` は GitHub に上がらず、誰にも見えないことを伝える
5. 今月の活用日数を伝える。比べる相手は先月の自分だけにする

短く終える。書くことがない日は記録しなくてよい。
