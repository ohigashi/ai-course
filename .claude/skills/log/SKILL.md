# /log

1. 最初に `node scripts/log.mjs` を実行する。止まったときは、案内どおり大東への相談を伝えて終える。`.local/` の内容を commit しない
2. 今日のやり取りから「どの仕事に AI をどう使ったか」の1行案を作り、受講者に見せて直してもらう。顧客名や数字の実データは書かない
3. 確定した1行を `.local/log.md` の末尾に `- YYYY-MM-DD 内容` の形で追加する
4. 記録できたら `node scripts/events.mjs add delegated` を実行する(「仕事をAIに任せた」の記録。日に1回だけ残り、このパソコンだけに保存される)
5. `git add activity.json` のあと `git commit -m "活用の記録" -- activity.json` を実行して push する。commit のメッセージに内容を書かない
6. 活用した日数は大東の一覧には出しません。日付のファイルは GitHub にあるので、大東が読むことはできます。内容は誰にも見えません。この3点を受講者に伝える
7. 今月と先月の活用日数を伝える。比べる相手は先月の自分だけにする

短く終える。書くことがない日は記録しなくてよい。
