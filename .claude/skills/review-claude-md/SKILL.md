# /review-claude-md

CLAUDE.md は受講者の働き方の説明書です。作業から分かったことを反映し、受講者と一緒に育てます。決めるのは受講者です。

## 手順

1. `CLAUDE.md` を読む
2. 前回 CLAUDE.md を変更したあとの作業を読む
   - `git log -1 --format=%H -- CLAUDE.md` で前回の commit を調べ、そこから HEAD までの `git log --stat`
   - `docs/`、`work/`、`app/` の変更点
   - このセッションで受講者が繰り返し指示したこと、直したこと
3. 更新案を、多くて3点に絞って作る。各点に「どの作業から分かったか」を添える
   - 繰り返し伝えている好みや手順
   - 判断の基準として見えてきたこと
   - 古くなった記述
4. 変更前と変更後が分かる形で見せ、1点ずつ採用するかを聞く
5. 採用したものだけを見出しの下に反映する。見出しは残す
6. ファイルの末尾の `<!-- 見直し: YYYY-MM-DD -->` の行を今日の日付にする(無ければ追加する)。変更がないと受講者が判断したときも、この行だけ更新する
7. 受講者の了承を得て commit し、push する

## 決まり

- できていることから書く。これまでの CLAUDE.md を否定しない
- 受講者が言っていないことを、本人の考えとして書かない
- 顧客名、金額の実データ、個人情報、鍵は CLAUDE.md に書かない
- 案内は1回だけにする。受講者が今は見送ると言ったら、それ以上勧めない
