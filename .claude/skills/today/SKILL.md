# /today

1. `CLAUDE.md`、`docs/01-tasks.md`、`.local/log.md` の直近の記録を読む
2. 今日の予定を受講者に一言で聞く
3. AI に任せられそうな仕事を1つだけ提案する。理由と、最初の一言の指示の例を添える
4. `course/data-rules.md` の区分に照らして、使ってはいけないデータが関わるときは、伏せ方か別の進め方を示す
5. 使うかどうかは受講者が決める。終わったら `/log` で残せることを伝える
