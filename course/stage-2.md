# 段階2 小さな自動化

目的は、いま手を動かしてみたい業務を1つ AI で実際に回し、かかる時間が変わることを体験することです。

## 進め方

`docs/02-log.md` がなければ `course/templates/02-log.md` からコピーします。

1. いまの手順を、順番どおりに Claude Code に説明します。「まず何を開いて、次に何をするか」の粒度で話します
2. 一番時間がかかる1か所だけを選びます。最初から全部を自動化しません
3. Claude Code に「この部分を任せたい。どんな方法があるか、選択肢を3つ出して」と聞いて、自分で選びます
4. 作ったものは `work/` に保存します。スクリプトでも、繰り返し使う指示文でも構いません
5. ダミーか、機微な部分を除いたデータで試します
6. 結果を自分の目で確かめます。正しいかどうかを判断するのは自分です

## 記録する

かかった時間の前後と月の回数を `docs/02-log.md` に書きます。チームのページの「減らした時間」になります。短くならなかったときも、そのまま書きます。何が難しかったかが次の材料になります。

## 終わったら

commit と push をして `/next` を入力します。
