# プロダクト化(フェーズ2 課題からアプリを作る)

目的は、自分のための道具を、他の人にも役立つものとして考え直すことです。ここではコードを書かず、言葉で決めます。

## 問い

- 同じことで困っている人は、社内や社外のどこにいますか
- その人は今、何を使って解決していますか
- その人が「使い続ける」理由は何になりますか

Claude Code に、自分の案への反対意見を出してもらいます。「この案が使われない理由を3つ挙げて」と聞きます。

## 仕様を書く

`docs/03-spec.md` がなければ `course/templates/03-spec.md` からコピーして、見出しごとに書きます。

- 誰のためか: 一人の具体的な人を思い浮かべて書きます
- 解く課題: 「課題の洗い出し」の課題を、その人の言葉で書き直します
- 最小の形: 1週間で作れる大きさにします
- 作らないもの: ここが一番大事です。思いついた機能のうち、今は作らないものを書きます
- 判断の基準: 迷ったときに何を優先するかを書きます

最小の形と作らないものは、自分で決めます。

## 次の「アプリ開発」の前に

アプリ開発はデスクトップアプリでも進められます。慣れてきたら、発展コース「ターミナルで使う」を試すと、できることが広がります。

仕組みを自分の言葉で確かめたいときは、`/mechanism` でお題を選べます。進む条件ではありません。

commit と push をして `/next` を入力します。
