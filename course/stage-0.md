# 段階0 環境づくり

目的は、自分専用の作業場所を持ち、Claude Code に自分の仕事を伝えることです。

## データの決まり

このコースでは、顧客データ、財務の実データ、個人情報、パスワードや API キーを Claude に読ませません。リポジトリにも置きません。練習にはダミーか、機微な部分を除いたデータを使います。

迷ったときは、そのデータを社外の人に見せてよいかで考えます。見せられないものは使いません。

詳しくは `course/data-rules.md` にあります。

## 誰に何が見えるか

自分のリポジトリは非公開です。大東は支援のために CLAUDE.md と docs/ を読むことがあります。チームに見えるのは、自分が了承した内容だけです。日々の記録の内容は誰にも見えません。この記録を人事評価には使いません。

## 自分の CLAUDE.md を書く

CLAUDE.md は、Claude Code が毎回最初に読む説明書です。ここに書いたことが、以後のやり取りの質を決めます。

Claude Code は次の問いを1つずつ受講者に聞き、答えをもとに CLAUDE.md の下書きを作ります。書き直しは受講者が判断します。

1. どんな仕事をしていて、どんな役割ですか
2. AIに一番任せたいことは何ですか
3. 文章や報告は、どんな形が読みやすいですか
4. どのタイミングで確認してほしいですか
5. 判断に迷ったとき、何を大切にしていますか
6. AIに渡さないものは何ですか

答えは、きれいな文章でなくて構いません。書き終えたら、1行目の `<!-- template -->` を消します。

CLAUDE.md は、一度書いて終わりにせず育てていくものです。作業が進むと、Claude Code が作業内容をもとに見直しを提案します。

## リポジトリに保存する

変更を commit して push します。GitHub にも保存され、大東が進捗を確認できるようになります。

大東をリポジトリに招待します。個人のリポジトリの仕組みとして、招待すると書き込みの権限が付きます。大東は読むためだけに使います。

## 終わったら

`/next` を入力します。条件を満たしていれば、段階1へ案内されます。
