# 発展コース

基本のコースと並行して、仕事に合うものから選びます。順番はなく、いつでも始められます。終えたら `docs/stepups/<コース名>.md` に、やったことと結果を書きます。

| コース | ファイル | 向いている人 |
|---|---|---|
| 繰り返しの指示をスキルにする | `skills.md` | 同じ依頼を何度も Claude に出している人 |
| 文章の基準を仕組みにする | `writing-check.md` | メールや資料など、外に出す文章が多い人 |
| 表のデータを読み解く | `data-analysis.md` | 売上や数字の集計が多い人 |
| 定例の仕事を自動で回す | `routines.md` | 毎週、毎月の決まった作業がある人 |
| ターミナルで使う | `terminal.md` | デスクトップアプリに慣れて、アプリ開発に進む人 |
| 仕事の道具とつなぐ | `connect-tools.md` | Notion、Slack、カレンダーなどを行き来している人 |
