# 評価の基準

提出のたびに、AI が「できたもの」と「プロセス」を別々に評価します。2つの重みは同じです。点数は付けず、観点ごとに「できている」「もう少し」「これから」の言葉で返します。

基準を満たすのは、できたものとプロセスのそれぞれで、「これから」が無く、半分以上の観点が「できている」のときです。どちらか一方だけでは次へ進めません。

期待の高さは課題のレベルに合わせます。レベル1では、「仕組みになっているか」を「同じ手順でもう一度できるか」と読み替えます。

## できたものの評価

| 観点 | 見ること |
|---|---|
| 課題の解決 | 求められたことが解けているか |
| 使いやすさ | 使う人が迷わず使えるか |
| 確かさ | 実際に動き、結果が正しいか |
| 仕組みになっているか | 一度きりでなく、繰り返し使えるか |
| 相手への配慮 | 使う人の事情や安全に配慮しているか |

## プロセスの評価

| 観点 | 見ること |
|---|---|
| 課題の捉え方 | 誰の何を解くのかを、依頼の言葉のままにせず捉え直したか |
| 選択肢の検討 | 複数の案を考え、なぜそれを選んだかを説明できるか |
| 捨てた判断 | 何を作らないと決め、その理由は何か |
| 確かめ方 | 動いたか、役に立つかをどう確かめたか |
| 途中の修正 | うまくいかなかったときに、何を見てどう変えたか |
| AIとの協働 | AIの答えを鵜呑みにせず、自分で判断したか |

うまくいかなかった試みや途中の方針変更は、減点せず評価の材料にします。

## フィードバックの書き方

できている点から書きます。次に伸ばす点は1つに絞り、具体的な次の一手を添えます。人と比べません。
