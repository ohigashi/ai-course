# コースの更新の記録

新しいものを上に書きます。`/next` はここを読んで、更新の内容を受講者の仕事につなげて伝えます。

## 2026-11-10 自分の進み具合をWebで見られるようになりました

- https://ac.hyperdash.app で、プログラム全体で何を学べるかを見られます
- https://ac.hyperdash.app/me に GitHub でログインすると、今いるフェーズ、進めている取り組み、作ったもの、これまでの歩みが見えます。見られるのは自分の分だけです
- 表示はおよそ1時間ごとに更新されます。自分で手元に記録した内容は、これまでどおり `/history` で見られます
- 手順と使い方のページは https://ac.hyperdash.app に移りました

## 2026-11-09 複数の取り組みを進められるようになりました

- 自分の仕事の名前で取り組みを作り、`/work` から始められます。いくつでも並行して進められ、休むことも、同じフェーズをやり直すこともできます
- 作業中のファイルは動きません。これまでの進み具合は、そのまま1つ目の取り組みとして引き継がれます
- 取り組みの名前と次にやることは、状態を保存するときに自動で大東に共有されます。顧客名や個人の事情は書かないでください。チームのメンバーに名前を見せるかどうかは、`/team` で別に聞きます
- どのフェーズからでも始められ、課題解決や発展コースもいつでも始められます

## 2026-11-09 フェーズに整理しました

- コースを4つのフェーズで見るようにしました。「作ってみる」「課題からアプリを作る」「繰り返して慣れる、たくさん作る」「人の課題も解決する」の順です。教材の見出しにも、どのフェーズかを書きました
- `/next` で、コースの全体の地図と、いまのフェーズが見えます
- 自分の作ったものを題材に、仕組みを自分の言葉で確かめる `/mechanism` を追加しました。進む条件ではなく、回答は誰にも読まれません。別のパソコンに移ると、お題の回答と完了の記録は引き継がれません
- 活用した日数は、大東の一覧には出さないことにしました。ファイルは GitHub にあるので、大東が読むことはできます
- 受講者のファイルは動きません。これまでの進み具合は、そのまま引き継がれます

## 2026-11-09 進み具合の自動共有

- いまの段階と次の一歩が、Claude Code を開いたときと `/next` のときに自動で大東に届くようになりました。報告の手間はありません
- 届くのは、段階の判定、残っている項目、次の一歩、取り込み済みのコースの更新だけです。自分の作業は、これまでどおり確かめてから保存します。チームの一覧には載りません

## 2026-11-09 社内での公開も完了に

- 社内の非公開のチャンネルや社内システムで使い始めたものも、「公開と運用」の公開として認めるようにしました。`docs/05-launch.md` の URL と同じ行に「社内」と書きます

## 2026-11-09 本番の業務で実データを使うときの決まり

- 作った仕組みを本番の業務で使うときに、領収書や取引一覧などの実データを扱える例外を定めました。会社の責任者と大東が個別に認めた業務に限ります
- 守ることは `course/data-rules.md` にあります

## 2026-11-09 伏せたデータを使える条件

- 会社の Team または Enterprise のアカウントなら、顧客名を伏せた文面や匿名にした数字を Claude に読ませて作業できるようになりました。実際の仕事に近い題材で試せます
- 使える条件と伏せ方は `course/data-rules.md` にあります。読ませた内容はリポジトリに保存しません

## 2026-11-09 課題解決とプロダクトコース

- これまでの歩みを `/history` で見られるようになりました

## 2026-11-09 日常の活用
