# 課題解決とプロダクト(フェーズ4 人の課題も解決する)

目的は、他の人の課題を考えて仕組みにする力を、数をこなして身につけることです。環境づくりを終えれば、いつでも始められます。

## 進め方

1. `/challenge` で、いまのレベルの課題を選びます
2. 節目ごとに Claude Code が問いかけます。答えが、考えた過程の記録になります
3. できたら `/challenge-submit` で提出します
4. できたものとプロセスの2つの評価が返ります

同じレベルの課題を2つ解き、どちらも基準を満たすと次のレベルに進めます。届かないときは、やり直すか別の課題を選べます。回数に制限はありません。

## 誰に何が見えるか

評価の中身と過程の記録は、自分だけに見えます。チームには、了承した場合にレベルを終えたことだけが見えます。大東には、課題ごとの完了日と、完了して保存した `challenges/` の作ったものが見えます。
