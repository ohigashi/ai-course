# 段階4 アプリ開発

目的は、仕様の「最小の形」を実際に動くものにすることです。コードは Claude Code が書きます。あなたは方向を決めて、動きを確かめます。

## 進め方

考え方と手順の詳細は https://ohgs.dev/claude-code-guide/ にあります。

1. `docs/03-spec.md` を Claude Code に読ませ、「この仕様を作る計画を、手順に分けて見せて」と伝えます。作り始める前に計画を確かめます
2. 技術の選択は、理由と一緒に選択肢を出してもらいます。こだわりがなければ、推奨を聞いて選びます
3. コードは `app/` に置きます
4. 1つ機能ができるたびに、自分の手で動かします
5. 動きがおかしいときは、「何をしたら、何が起きて、本当はどうなってほしいか」の3点を伝えます
6. 区切りごとに commit します

## 確かめる

`docs/04-check.md` がなければ `course/templates/04-check.md` からコピーします。自分が実際に試したことと結果を書きます。テストが通ったという報告だけで終わらせず、画面を自分で触ります。

この段階でも、顧客データ、財務の実データ、個人情報、鍵は使いません。鍵が必要になったら、コードに直接書かず、大東に相談します。

## 終わったら

commit と push をして `/next` を入力します。
