# チームで作る(フェーズ4 人の課題も解決する)

目的は、一人で身につけたことを持ち寄り、仲間と一緒に仕事を前に進めることです。基本のコースと並行して、「小さな自動化」と「課題の洗い出し」を終えたあとから参加できます。組む相手がいないときは、無理に進めなくて構いません。

## 進め方

1. `/team` で、チームの取り組みを見ます
2. 同じ課題の人や、自分の成果が役立ちそうな人を探します。Claude Code が候補を示しますが、決めるのはチームです
3. チームのフォルダを開いて、`/project-new` で共同プロジェクトを立ち上げます。2〜3人で、短い期間で終わる大きさにします
4. `/project-next` で、自分のタスクを進めます。変更は、もう一人に確認してもらってから反映します
5. `/project-status` で、全体の進み具合と止まっているものを確かめます
6. うまくいったやり方は、`/review-team-rules` でチームの決まりに加えます

仕組みを自分の言葉で確かめたいときは、`/mechanism` でお題を選べます。進む条件ではありません。
