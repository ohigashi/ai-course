# 課題の洗い出し(フェーズ2 課題からアプリを作る)

目的は、AIで解く課題を自分で1つ選ぶことです。ここで選んだ課題が、この先のすべての題材になります。

## 業務を棚卸しする

`docs/01-tasks.md` に、1週間の仕事を書き出します。1回あたりにかかる時間も一緒に書きます。

Claude Code に話しかけながら進められます。「今週やったことを思い出すのを手伝って」と伝えてください。

3件以上あれば次に進めます。多いほど、選びやすくなります。

## 1つ選ぶ

選ぶときの問いは3つです。答えを決めるのは受講者です。

- 毎週や毎月、繰り返していますか
- 終わったときの正解が、自分で判断できますか
- うまくいったら、誰かが喜びますか

最初は小さなものを選びます。1回30分以上かかる繰り返しの作業は、題材に向いています。

## 課題を言葉にする

`docs/01-problem.md` の4つの見出しの下に書きます。

- 誰の: 困っている人。自分自身でも構いません
- 何が困っているか: 具体的な場面で書きます
- いまどうしているか: 今の手順を書きます
- どうなればよいか: 終わったときの姿を書きます

書き終えたら、1行目の `<!-- template -->` を消し、commit して push します。

## 終わったら

`/next` を入力します。
