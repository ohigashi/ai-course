# 段階5 公開と運用

目的は、作ったものを実際に人に使ってもらい、反応を見て直すことです。作って終わりにしません。

## 公開の前に

- 公開するものに、顧客データ、個人情報、鍵が入っていないことを Claude Code と確かめます
- 誰に見せるかを決めます。最初は `docs/03-spec.md` の「誰のためか」に書いた一人で十分です
- 公開の方法は Claude Code に選択肢を出してもらいます。手順は https://ohgs.dev/claude-code-guide/ にあります
- 会社の名前で公開するときは、先に大東に相談します

## 公開したあと

1. 公開先の URL を `docs/05-launch.md` に書きます
2. 実際に使う人の様子を見ます。「どこで止まったか」を聞きます
3. 1つ直して、もう一度見てもらいます。直したことを記録します

## 終わったら

commit と push をして `/next` を入力します。ここまでで基本のコースは終わりです。続きは発展コースから選べます。
