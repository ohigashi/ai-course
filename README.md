# AdagioのAI活用推進プログラム

Claude Code のセットアップから、課題の洗い出し、プロダクト化、アプリ開発までを、自分の仕事を題材に進めるコースです。

はじめ方は手順のページを見てください。 https://ohgs.dev/ai-course/

進め方は使い方ガイドにまとめています。 https://ohgs.dev/ai-course/guide/

全体は4つのフェーズです。「作ってみる」「課題からアプリを作る」「繰り返して慣れる、たくさん作る」「人の課題も解決する」の順がおすすめです。どのフェーズからでも始められ、やり直せて、同じことを繰り返せます。実際の課題解決、業務改善、プロダクト開発を進めながら学びます。

自分のリポジトリができたら、Claude Code に `/next` と入力します。いまのフェーズと、次にやることが分かります。

このリポジトリはテンプレートです。自分のリポジトリは非公開で作ります。顧客データ、財務の実データ、個人情報、鍵は置きません。
