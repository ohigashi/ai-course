# 事業でAIを活用するコース

Claude Code のセットアップから、課題の洗い出し、プロダクト化、アプリ開発までを、自分の仕事を題材に進めるコースです。

はじめ方は手順のページを見てください。 https://ohgs.dev/ai-course/

全体は6段階です。環境づくり、課題の洗い出し、小さな自動化、プロダクト化、アプリ開発、公開と運用の順に進みます。

自分のリポジトリができたら、Claude Code に `/next` と入力します。いまの段階と、次にやることが分かります。

このリポジトリはテンプレートです。自分のリポジトリは非公開で作ります。顧客データ、財務の実データ、個人情報、鍵は置きません。
